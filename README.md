# R and J Cellphone Accessories and Repair Shop

A fast, easy-to-use one-page storefront website created for **R and J Cellphone Accessories and Repair Shop** (Don Carlos, Bukidnon). 

Designed to help local customers easily check repair prices, view available accessories, find shop hours, and submit repair requests online.
